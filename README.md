# 修好这条路 · 浏览器测试版

一个温暖、轻量的道路旋转解谜游戏。不是只接通一条路：后半段需要让两辆送货车依次出发，在两次发车之间切换共享岔口，把面包和鲜花分别送到正确的目的地。

## 项目状态

- 独立项目及 GitHub 私有仓库：https://github.com/kafuunochino/fix-the-road 。
- 已有纯规则模块、10 个手工设计关卡及可重放解法、29 项自动化测试。
- 已保存一版尚未通过浏览器验收的 DOM/SVG 界面原型，包含车辆动画、预览、撤销、选关、存档及音效交互。当前暂停界面扩展，等待抖音优先的运行时架构方案验证。不能将此快照当作已验收的小游戏包。
- 私有仓库和说明已建立。开发侧负责每轮开发或修改后的源码同步及远端提交核验，不将尚未同步的本地代码描述为已备份。
- 当前是原生 HTML / CSS / JavaScript 浏览器原型，不是已接入抖音或微信 SDK 的小游戏包。

## 玩法目标

1. 点击道路，将其顺时针旋转 90°。
2. 连接车库和当前车辆的目标建筑，通过路线预览检查连通情况。
3. 发车后观察车辆沿道路行驶。
4. 第 5–10 关加入“双车接力”：黄色早餐车去面包店，紫色送花车去花园。完成第一趟后，切换橙色岔口，为下一辆车重新分流。
5. 以较少的旋转步数取得更好评价。无倒计时、无体力、无广告。

原型目标交互包括手机竖屏触控、鼠标、关卡选择、撤销、重置、安全的本地存档及可关闭音效。正式路线以抖音小游戏优先、后续微信兼容为目标，具体适配仍需验证。

## 本地运行

需要 Node.js 20 或更高版本。不需要安装依赖。

```sh
npm test       # 规则和关卡解法测试
npm run check # JavaScript 语法及规则测试
npm run serve # 开发服务器，默认端口 4172
```

开发者启动服务器后可访问 http://localhost:4172 查看未验收的浏览器原型。可以通过 PORT 环境变量指定其他端口。不会自动公开发布。

## 目录

- `index.html`、`style.css`、`src/app.js`、`src/art.js`：暂存的 DOM/SVG 原型，不等于抖音小游戏运行时。
- `src/rules.js`：无 DOM、无存储依赖的纯规则与状态变更。
- `src/levels.js`：10 个手工布局、初始旋转和参考解法。
- `test/rules.test.js`：可用 Node 内置测试运行器执行的测试。
- `server.mjs`：无第三方依赖的开发服务器。
- `qa/TEST_PLAN.md`：交互和浏览器回归测试计划。

## 测试责任与验收

开发侧负责道路连通、错误目的地、越界、岔口切换、撤销状态、关卡可解性以及浏览器流程回归。用户负责实际游玩体验和建议，而不是替开发侧排查已知流程错误。

已有规则检查：29 / 29 通过。所有 10 关都有可重放的完整解法，且开始时未解开。浏览器 UI 流程尚未运行，不能据此宣称可玩性已经验收。

## 美术与数据

美术使用原创 CSS / SVG / Canvas 代码绘制，不购买素材，不引用外部图片、字体或音效服务。浏览器原型用 Web Audio 生成轻量提示音，并提供静音控制；平台运行时音频适配尚未验证。

不需要账户、云服务、支付或广告。完成后的进度仅保存在本浏览器 localStorage；无痕模式、清理站点数据或换设备可能导致进度丢失，不把本地游戏存档当作源码备份。

## 测试版边界

- 未接入抖音 / 微信小游戏 SDK、平台登录、云存档、好友分享或广告。
- 未做商业化、买量、留存统计或正式发行。
- 本项目不会自行创建公开网站或公开 GitHub 仓库。
- 移动设备实机兼容性需按测试计划继续验证；桌面模拟不等同于实机验收。
