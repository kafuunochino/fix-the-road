# 修好这条路

**停止维护 · 实验性小游戏原型 · 游戏废案**

这个项目记录一次小游戏想法验证，现已结束迭代。保留代码供研究其规则、Canvas 界面和平台适配方式，不再作为持续开发或商业上线的产品。**不是正式发行游戏，不提供生产可用、平台审核通过或所有真机兼容的承诺。**

## 原型内容

道路旋转、路口切换与路板吊装的城市运输解谜实验。

50 个确定性工段；路线预览、发车、制动故障动画、工时与容错、撤销和免费重开。

- JavaScript / Canvas 2D；游戏控件绘制在 Canvas 内。
- 本地存档和确定性规则，不依赖在线服务器。
- 保留抖音适配器与可复现构建；浏览器版用于研究和本地调试。
- 真实广告默认关闭；金币仅为本地虚拟数据，没有充值、提现或交易。
- 失败可免费重开；并非每个失误后的局面都仍有解。

## 最后一次收尾

保留移动端全屏及安全区适配；补充按压反馈，并将旋转、道岔、发车、完成、故障分为五种原创合成音效。

三款原型共同修正原生音频容错：首次 seek 失败仍尝试播放、后台禁止新声音、音频 pause/destroy 异常不阻断游戏暂停或清理。保留音效开关和已有存档选择。

这次是有限的收尾整理，**不是完整的表现力重制**。现有场景仍较简化，动效、音效、UI 信息层级和游戏节奏不足以代表成熟作品；自动化规则测试也不能证明主观体验优秀。

## 本地运行

需要 Node.js 20 或以上。在仓库目录执行：

```sh
npm run build
npm test
npm run serve
```

按终端输出打开本地地址。单文件浏览器构建为 `deliverables/fix-the-road-demo.html`。平台候选包位于 `dist/douyin/`；它只是构建输出，运行构建不会上传、送审或正式发布。

原生构建中的 ES2018 兼容工具如依赖外部安装路径，请先阅读 `docs/DOUYIN_COMPILER_COMPATIBILITY.md`（若存在）及构建脚本。项目是固定模块图原型，不是通用工程脚手架。默认 AppID 已清空，防止废案误传到其他游戏。需要研究平台适配时，请显式设置自己的 DOUYIN_APP_ID；历史 AppID 不授予任何账号或发布权限。

## 代码入口

- `src/canvas-game.js`：Canvas 界面与交互。
- `test/`：规则、存档、输入和生命周期回归。
- `scripts/`：构建与验证工具。
- `config/douyin.json`：平台构建配置。
- `docs/`、`artifacts/`：历史设计与测试记录，不代表当前发行承诺。
