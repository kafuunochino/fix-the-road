- canonical AppID、显式空覆盖、测试 ID 覆盖、非法值拒绝；测试结束恢复真实 ID，逐项验证 SHA-256 manifest。

## 受保护侧边栏模拟测试 8 项

- 在 Canvas 创建前同步注册 onShow 并检查支持，不自动导航。
- 缺失、不支持、能力检查失败时不显示可用导航。
- 点击调用真实 API 路径，pending 防重，成功回调不伪造返回。

- 旧回调不能覆盖新状态；destroy 清理监听并结清挂起请求。
